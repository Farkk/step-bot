# Правила для агентов проекта «ШАГ»

Отвечай на русском. Всегда задавай пользователю вопрос по новой задаче или проектному решению; выполняй независимую часть работы, пока ждёшь ответ. Для задач по этому репозиторию используй skill `$step-project` из `skills/step-project/SKILL.md`. Если skill недоступен в окружении, следуй его инструкциям непосредственно.

Перед изменением интерфейса сверяйся с `DESIGN_SYSTEM.md`, а перед реализацией поведения — с нужными разделами `TECH_SPEC.md`. Фактическое состояние и принятые решения веди в `docs/PROJECT_GUIDE.md`; обновляй его вместе с расширением функциональности. Вопросы по незафиксированным продуктовым правилам задавай пользователю, продолжая независимую работу.

После изменений Mini App пересобирай и перезапускай контейнер приложения командой `docker compose up --build -d app`. После запуска проверяй состояние контейнера и доступность `/health/ready` и `/app/`.
