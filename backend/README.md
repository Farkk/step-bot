# Сервер «ШАГ» на Laravel

Этот каталог содержит API и бот MAX на Laravel 13 и MySQL. React Mini App и кабинет собираются из `../web` в `public/app` и `public/admin` командой `sh ../scripts/build-php-assets.sh` из корня репозитория.

Локальный запуск, настройка Beget, миграции и cron описаны в [главном README](../README.md). Текущее состояние реализации — в [PROJECT_GUIDE.md](../docs/PROJECT_GUIDE.md).
